# PathTrace app bundle

Exported by `pathtrace export` from `junyi-10k` and `junyi-10k` on 2026-10-03. See `meta.json` for
the exact runs and their test metrics.

The student histories in `data/` are 300 test-split students from the
[Junyi Academy Online Learning Activity Dataset](https://www.kaggle.com/datasets/junyiacademy/learning-activity-public-dataset-by-junyi-academy), which is licensed [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This bundle is derived
from it and shared under the same license. Concept names are machine-translated
(see `ml/resources/README.md`).
